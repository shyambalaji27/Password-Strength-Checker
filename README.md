# 🔐 Password Strength Checker

A modern and responsive **Password Strength Checker** built using **HTML, CSS, and JavaScript**. This web application provides real-time feedback on password strength, helping users create secure passwords by analysing key security criteria such as length, character diversity, and complexity.

## 🌐 Live Demo

**Website:** https://shyambalaji27.github.io/Password-Strength-Checker/

---

## 📖 Overview

Weak passwords are one of the most common causes of compromised online accounts. This project demonstrates how client-side JavaScript can be used to analyse password strength instantly without transmitting user data, providing a fast and privacy-friendly experience.

---

## ✨ Features

* 🔒 Real-time password strength analysis
* 📊 Animated strength meter

## 🔍 Password Evaluation Criteria

The application evaluates passwords using several security rules:

* Minimum password length
* Uppercase letters
* Lowercase letters
* Numeric digits
* Special characters

Based on these checks, it displays a strength level ranging from **Very Weak** to **Very Strong**.

### 🔒 Security Note

This application performs all password analysis locally in your browser. Passwords are **not stored, transmitted, or shared**, helping to preserve user privacy while demonstrating password-strength evaluation techniques. Strong, unique passwords and password managers remain best practices for account security.
